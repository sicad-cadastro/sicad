ℹ️ Como funciona — pipeline otimizado
Detecção: TinyFace (rápido) + SSD MobileNet v1 como fallback de segurança.
Pré-processamento: redimensionamento automático pra resolução ótima (~1000px).
TTA (Test-Time Augmentation): cada rosto gera 2 descritores (original + espelhado) e a comparação usa a menor distância — sobe ~3% de acurácia.
Limiares calibrados:
  • < 0,50 → mesma pessoa (alta confiança)
  • 0,50 a 0,60 → possível match (verificar manualmente)
  • > 0,60 → pessoas diferentes
